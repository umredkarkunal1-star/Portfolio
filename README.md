# 🚀 Kunal Umredkar Portfolio Website

A modern, futuristic, and fully responsive personal portfolio website built using **HTML, CSS, and JavaScript**. This portfolio showcases my skills, projects, education, and career aspirations while providing an interactive user experience with smooth animations, glassmorphism design, and an AI-powered assistant.

## 🌟 Features

### 🎨 Modern UI/UX Design

* Futuristic glassmorphism interface
* Neon gradient effects
* Smooth animations and transitions
* Fully responsive design
* Dark/Light theme toggle

### 🖱️ Interactive Experience

* Custom animated cursor
* Particle background system
* Scroll-based animations
* Animated statistics counters
* Typing text effect

### 👨‍💻 Portfolio Sections

* Hero Section

### 🤖 AI Portfolio Assistant
