## ✨ Features

- Animated hero section with a typing effect and 3D Spline canvas background
- Scroll progress indicator and custom cursor glow effect (desktop)
- Responsive navigation with a mobile hamburger menu
- About section with info cards and animated stat counters
- Skills section with categorized, animated proficiency bars
- Project showcase cards with live demo links
- Certificate showcase with an embedded PDF credential
- Contact form that sends a message directly via WhatsApp
- Social links to GitHub, LinkedIn, Instagram, Email, and WhatsApp
